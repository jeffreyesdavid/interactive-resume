ai-guardian: Shadow AI Agent Scanner

Oct 2026
  • Free, local scanner that discovers the AI agents on a machine (AI apps, coding agents, browser extensions, local model servers, and MCP servers that connect agents to files and accounts) and maps what each one can access.
  • Flags risky setups: API keys stored in plain text, agents with access to the whole drive or SSH keys, permission prompts turned off, unpinned or unencrypted MCP servers, and local AI servers exposed to the network.
  • Brings the discover-and-map model of enterprise AI agent security (e.g. CrowdStrike Falcon Guardian) to individuals and small businesses. Read-only, with every secret masked in output.
  • First scan of my own laptop found 16 AI agents; that real-world run exposed 3 bugs that synthetic tests missed, which I fixed and covered with regression tests (23 tests total).
  • Project page: jeffreyesdavid.github.io/ai-guardian

tx-guard: Crypto Transaction Safety Checker

2026
  • Python command-line tool that checks a crypto transaction before it is signed and explains the risk in plain English.
  • Try it live: txguard-jeffrey.streamlit.app, a web version anyone can use without installing anything.
  • Matches every address in a transaction against 2,500+ known scam addresses from a public threat-intelligence list.
  • Detects the most common wallet-draining tricks: unlimited token approvals, NFT "approve all," and permit signatures.
  • Simulates the transaction on the live Ethereum network to show exact losses (e.g. "you lose 500 USDC") and surface approvals hidden inside other calls.
  • Covered by 37 automated tests; validates malformed input instead of silently misreading it.
