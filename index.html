tx-guard: Crypto Transaction Safety Checker

2026
  • Python command-line tool that checks a crypto transaction before it is signed and explains the risk in plain English.
  • Matches every address in a transaction against 2,500+ known scam addresses from a public threat-intelligence list.
  • Detects the most common wallet-draining tricks: unlimited token approvals, NFT "approve all," and permit signatures.
  • Simulates the transaction on the live Ethereum network to show exact losses (e.g. "you lose 500 USDC") and surface approvals hidden inside other calls.
  • Covered by 37 automated tests; validates malformed input instead of silently misreading it.
